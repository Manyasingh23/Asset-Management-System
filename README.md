# Asset Management System

A web-based application built using Java, Spring Boot, and MySQL to manage company assets and employee assignments.

## Features
- User authentication using JWT.
- Role-based access for Admin and Employee.
- Create, view, update, and delete asset records.
- Manage employee records.
- Track asset availability and employee assignments.
- REST APIs for backend operations.

## Technologies Used
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Authentication:** JWT
- **Tools:** Maven, Git, GitHub, Postman

## Project Purpose
This project demonstrates backend development, REST API implementation, database integration, CRUD operations, and authentication in a Java-based web application.
